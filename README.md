VisionMouse · 视觉拟人鼠标
截图识别 · OCR 定位 · 类人点击 —— 一个跑在 Windows 桌面上的自动化小工具：截取任意窗口画面，用系统自带 OCR 找出文字位置，再按类人轨迹移动鼠标点击；在此之上还提供了「记录连线反复执行」「跑圈模板」「答题模式」三套流程。
当前版本：v2.2.0（正式发布版 · 已通过 BETA 实跑验证）
功能一览
1. 截图识别 + OCR
- 选择任意窗口（下拉刷新 / 直接在预览画面上点一下即可选定目标）
- 一键「截图识别」，用 Windows 自带 OCR 提取文字，列表显示 文字 / 坐标 / 字高
- 支持按文字搜索过滤，选中一行即可作为点击目标
- 「▶ 实时同步」可定时刷新画面，跟随窗口内容变化
- 纯本地识别，不联网、不上传截图
2. 拟人点击
- 三次贝塞尔轨迹 + 缓入缓出，落点带轻微过冲回落，不是瞬移
- 点击期间按 ESC 可随时中止
- 仅在本机模拟鼠标，不注入、不修改目标程序
3. 记录连线 · 反复执行
适合「固定几个位置轮流点」的场景：
- ● 开始记录：点一下画面就记一个坐标点，可撤销、可清空
- ▶ 开始反复：按「点击间隔 / 每轮间隔」循环执行整条连线
- 可选 点击后自动找「确定」确认
- 可选 自动识别红色定位标（跳过），避免误点标记
- 框选范围（区域内跳过）/ 点选跳过（单点跳过）、可清除
- ⏸ 暂停 / ⟲ 从头重来
4. 跑圈模板 · 地图锚定
给「沿地图路线跑圈」类场景用的模板：
- 两点校准：量一段已知距离，算出「像素/米」，把屏幕像素映射到真实距离
- 400 米操场一键预置，也可自定义直道长度、半径、角度、点数后「生成连线」
- 按配速：填分钟/公里（如 5.0 表示 5 分/公里），按配速决定每个点的停留时间
- 面板里的折线图实时显示配准健康度（置信度曲线 / 失败红点 / 拒判线），每秒自动刷新
5. 答题模式
自动读题 → 文字推理 → 自动作答，支持三种推理来源：
推理来源
说明
云端 API
兼容 OpenAI 协议的接口，默认 https://api.deepseek.com/v1 + deepseek-chat，填自己的 API Key 即可
元宝（RPA）
直接操作本机已登录的腾讯元宝客户端（截图 → 粘贴题目 → 回车发送 → OCR 读回复）
豆包（RPA）
同上，操作豆包客户端
支持的题型与动作：
- 单选题 / 多选题：识别选项字母，按答案自动勾选
- 判断题：只认明确的「正确 / 错误」结论；客户端若回「无正确选项」直接跳过，不瞎猜
- 编程题：识别「指尖实验室」页面，让模型给出完整代码 → 自动新建/复用源文件 → 粘贴进编辑器 → 选择入口文件 → 按需点「提交练习」
- 自动提交开关（默认开，可关掉只填不交）
- 每题间隔可调（默认 3 秒），支持 ⏸ 暂停 / ■ 停止
- 答完一页自动尝试「下一页 / 下一题」继续
- 任何一步没拿到可靠答案都会跳过该题并写日志，不会盲填 A
RPA 模式使用前，请先手动启动并登录对应客户端，把它放在屏幕上可见的位置。首次使用需要让 VisionMouse 探测一次窗口布局（点一次「截图识别」并选中该客户端窗口即可），之后会缓存布局。
6. 检查更新
- 启动时静默检查 GitHub Releases 最新版本（不打扰，仅在有新版本时弹窗）
- 「关于」窗口内也有「检查更新」按钮，可手动检查
- 有新版本时弹窗提示，支持「前往下载」或「跳过此版本」
系统要求
- Windows 10 / 11（需要系统自带 OCR，建议已安装中文语言包）
- PowerShell 5.1（系统自带，用于调用 OCR 接口）
- 运行发行版：无需安装 Python
- 从源码运行：Python 3.9+，依赖 pywin32、Pillow（numpy 可选，装了更稳）
安装与使用
安装版
下载 视觉拟人鼠标_安装包_v2.2.0.exe，双击安装（默认装到当前用户目录，无需管理员权限）。
绿色版
下载 视觉拟人鼠标.exe，放到任意目录双击即可。配置会保存在 exe 同目录的 visionmouse_config.json。
三个典型用法
1. 点一个按钮：选目标窗口 → 截图识别 → 搜索文字 → 选中 → 「拟人单击」
2. 固定流程循环：开始记录 → 依次点完各位置 → 设置间隔 → 开始反复
3. 刷练习页：选中浏览器窗口 → 选推理来源（云端 API / 元宝 / 豆包）→ 填好 Key 或登录客户端 → 「开始答题」
常见问题
跑 RPA 时提示「没找到元宝/豆包窗口」
客户端可能被最小化到托盘或进程已退出。把它恢复成正常大小并保持可见后重试；程序会优先选择正常尺寸的窗口。
OCR 识别文件名丢了小数点（WordCountjava）
整窗截图时小字号里的点号容易被引擎吃掉。程序对文件名区域做了局部放大识别，正常情况下能恢复成 WordCount.java；比较文件名时也做了忽略标点的兜底匹配。
答题模式会不会把已经答过的题重答
会。每轮都是重新读当前页面并作答，不做「已答跳过」。
「自动提交」有风险吗
有。开启后答完即提交并翻页。建议先关掉它，确认答案正确后再打开。
想中途停下
点击类操作按 ESC 中止；答题 / 循环用界面上的「暂停 / 停止」按钮。
从源码运行
git clone https://github.com/Jaymin-chang/VisionMouse.git
cd VisionMouse
pip install pywin32 pillow numpy
python app.py
目录内的 ocr-lines.ps1 是 OCR 调用脚本，必须与 app.py 放在同一目录；version.txt 提供版本号。
打包
仓库外的构建脚本会调用 PyInstaller 生成单文件无控制台 exe，并用 Inno Setup 生成安装包；exe 与安装包均嵌入 vm.ico 图标。
